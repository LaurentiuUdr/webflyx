# Webflyx - Git Sandbox

This repository contains sandbox files created exclusively for learning Git and GitHub. It has no practical utility or functional application; it serves solely as a historical record of my learning progress.

As part of the Boot.dev Git curriculum, this project demonstrates practical experience with the following version control fundamentals:

* **Local Repository Management:** Initializing a new repository (`git init`) and inspecting its current state and commit history (`git status`, `git log`).
* **The Staging Area:** Moving modified files from the working directory to the staging area to prepare them for a commit (`git add`).
* **Committing Changes:** Saving snapshots of the project safely using clear, descriptive messages (`git commit`).
* **Branching and Merging:** Creating isolated branches for new features or experiments (`git branch`, `git switch`), and cleanly integrating those changes back into the main branch (`git merge`).
* **Working with Remotes (GitHub):** Connecting the local repository to a remote server (`git remote`), uploading local commits (`git push`), and syncing changes from the remote repository (`git pull`, `git fetch`).
* **Collaboration & Maintenance:** Handling merge conflicts, understanding repository forks, and the basics of Pull Requests.
